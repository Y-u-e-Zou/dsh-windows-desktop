DSH-Windows桌面版

帮助与说明

这是什么

DeepSeek Harness 是一个开源的 AI 编码智能体框架（agent harness）。你可以把它理解成一个强大的 AI 编程助手：它接入 DeepSeek 大模型，在你的电脑上读写文件、执行命令、规划并执行任务，帮你完成编程和各种自动化工作。本桌面端把它包装成一个独立的 Windows 桌面应用。

桌面精灵

点击「桌面精灵」后，桌面会出现一个独立的鲸鱼娘小窗口（可拖动、始终置顶），头顶显示当前本地时间（实时刷新）。再次点击菜单「桌面精灵」即可关闭/唤出。

精灵下方有两个小按钮：⏰ 闹钟和⏱ 倒计时。设定闹钟后，到设定时刻会响铃；设定倒计时后，倒计时归零会响铃。响铃时气泡会变红闪烁、精灵上下跳动，并发出提示音，持续几秒后自动停止。

工作区

工作区是什么：工作区（workspace）是 Harness 这个 AI 助手在你电脑上「干活」的根目录。AI 读文件、写文件、执行命令、创建项目，都发生在这个目录范围内。

为什么要设定：设定工作区，就是告诉 AI「请在这个文件夹里工作」。这样 AI 的操作范围会被限定在你指定的目录内，既方便你管理它生成或修改的文件，也更安全——它不会去乱动这个目录之外的其他文件。建议单独建一个空文件夹作为工作区。

本客户端的定制改动

本客户端在 DeepSeek Harness 本体之上做了以下定制，使其更适合桌面使用：

· 目录选择器：设置工作区时改用 Windows 原生文件夹框（PowerShell 实现，绕开了部分机器上会崩溃的原生组件），默认定位到安装目录。

· 删除保护：AI 删除文件/目录时，会移到工作区内的 垃圾箱 文件夹，而非彻底删除；需要时可从该文件夹恢复，不需要时再手动彻底删除。

· Full access 风险警告：切换到 Full access 权限时，会弹出高风险警告，需你明确确认后才生效。

· 多账号隔离：每个 API Key 独立数据目录，聊天记录互不可见。

以上定制在升级 Harness 本体后会自动重新应用，无需手动处理。
